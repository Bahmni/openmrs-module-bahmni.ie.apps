# OpenMRS module Bahmni IE Apps

## Build


Clone the repository and build the omod
   
    https://github.com/Bahmni/openmrs-module-bahmni.ie.apps
    cd openmrs-module-bahmni.ie.apps
    ./mvnw clean install
